# Product

## Register

product

## Users

Owner of a home Xiaomi router, managing VPN for phones, a television and other Wi-Fi devices. Russian is the main interface language; English remains supported.

## Product Purpose

Show the active routing first, make server changes straightforward, and keep VPN working through automatic selection and verified backups. Shared domains and server-specific domains have separate ownership.

## Brand Personality

Clear, calm, polished. Use familiar words and visible actions instead of implementation terminology.

## Anti-references

The user rejects confusing nested expanders, hidden server controls and a cluttered subscription screen. Avoid adding competing ways to configure the same decision.

## Design Principles

- Show the server actually in use, not only a saved preference.
- Let users act directly on a server name where they see its status and ping.
- A manual server choice retains automatic recovery when that server fails.
- Preserve separate decisions for the common list and DeepSeek.
- Reuse the existing interface, with visible pending and error states.

## Accessibility & Inclusion

Use native buttons, keyboard focus, accessible selection and busy states. The existing responsive layout and theme settings remain supported.
