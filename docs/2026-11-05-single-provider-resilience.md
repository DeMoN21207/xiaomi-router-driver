# Устойчивость на одной подписке

Пользователь просит уменьшить сбои VPN и явно исключил настройку второй подписки. Сохраняем раздельные списки общего VPN и DeepSeek, период отказа 5 секунд, восстановление 60 секунд и режим `keep`. Текущая проверка HTTPS подтвердила Sweden #4, Latvia и Poland; Sweden #1 и Finland не прошли проверку.

На прошивке `/etc` находится в ramfs, используется cron-watchdog. До изменения он проверял наличие процесса раз в минуту, а каталог блокировки без владельца мог остаться после аварийного прерывания стартера. На роутере есть `flock`, `/data` и USB находятся на постоянных файловых системах; постоянная копия cron содержит ссылку на приложение.

Bootstrap сохраняет совместимую cron-строку и добавляет проверки через 10/20/30/40/50 секунд. Каждый дочерний запуск помечен `--once` и не создаёт новых таймеров. При удалении bootstrap отложенные проверки ничего не запускают. Обновление и его блокировки учитываются при каждой проверке. Для старта используется неблокирующий `flock` с освобождением при гибели процесса; дочерний VPN Manager не наследует дескриптор блокировки. После захвата блокировки повторно проверяются процесс, существование bootstrap и состояние обновления. Блокировка удерживается до подтверждения запуска приложения. На системах без `flock` остаётся совместимый mkdir fallback. Установка bootstrap выполняется атомарно.

## Результаты установки 2026-11-05

- На роутер установлен код `52a67a2`, сборка `2026-11-05T18:04:57Z`, MD5 бинарника `ee8aa5040590ef81bf20710d13276514`. Установка с автоматическим откатом подтверждена; резервная копия: `/mnt/usb-4d3e56cb/vpn-manager/backups/single-resilience.mKJDcK`.
- Полный `go test -race ./...` и `go vet ./...` прошли. Shell-тест воспроизводит конкурентный запуск и проверяет один экземпляр, отсутствие рекурсивных таймеров и безопасное удаление bootstrap. Независимая проверка кода завершена без оставшихся существенных замечаний.
- При контролируемом SIGKILL только VPN Manager HTTP восстановился за 8,668 секунды. Успешные VPN-запросы по Wi-Fi появились примерно за 13 секунд; готовность всех проверок — за 17,049 секунды. На время испытания был предусмотрен отдельный отложенный запуск.
- После восстановления подтверждены один процесс приложения, свободная блокировка запуска и единственная корректная строка cron как в рабочем, так и в постоянном файле.
- После повторных проверок HTTPS через VPN обе политики используют три кандидата: Sweden #4, Latvia #2 и Poland. Sweden #1 и Finland #2 исключены только из автовыбора после повторных неудачных проверок; сохранённые правила не удалены.
- Контролируемая недоступность активного туннеля Sweden #4 вызвала переключение на Poland за 13,031 секунды. Временные тестовые правила firewall удалены, VPN-запросы по Wi-Fi снова успешны.
- Сверка с исходным снимком подтвердила сохранность 5 правил, 155 доменов/IP, двух отдельных политик, настроек маршрутизации и автоматизации. Единственное изменение настроек — список проверенных кандидатов. Остались `autoRecover=true`, `providerFailover=false`, подтверждение отказа 5 секунд, восстановление 60 секунд и режим `keep`.
- Итоговая проверка через Wi-Fi и DNS роутера: ya.ru — HTTP 302, YouTube — 200, ChatGPT — 200, DeepSeek API — 401 без API-ключа.

Время восстановления измерено в этих испытаниях и не является гарантией для любого сбоя. Общий отказ единственного VPN-провайдера, отключение питания, USB и физического WAN не покрываются переключением между его серверами; эти отказы не имитировались.
