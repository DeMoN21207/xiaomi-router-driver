# Устойчивость на одной подписке

Пользователь просит уменьшить сбои VPN и явно исключил настройку второй подписки. Сохраняем раздельные списки общего VPN и DeepSeek, период отказа 5 секунд, восстановление 60 секунд и режим `keep`. Текущая проверка HTTPS подтвердила Sweden #4, Latvia и Poland; Sweden #1 и Finland не прошли проверку.

На прошивке `/etc` находится в ramfs, используется cron-watchdog. Сейчас он проверяет наличие процесса раз в минуту, а каталог блокировки без владельца может остаться после аварийного прерывания стартера. На роутере есть `flock`, `/data` и USB находятся на постоянных файловых системах; постоянная копия cron содержит ссылку на приложение.

Bootstrap сохранит совместимую cron-строку и добавит проверки через 10/20/30/40/50 секунд. Каждый дочерний запуск помечен `--once` и не создаёт новых таймеров. При удалении bootstrap отложенные проверки ничего не запускают. Обновление и его блокировки учитываются при каждой проверке. Для старта используется неблокирующий `flock` с освобождением при гибели процесса; дочерний VPN Manager не наследует дескриптор блокировки. На системах без `flock` остаётся совместимый mkdir fallback. Установка bootstrap выполняется атомарно.

После проверки кода и установки обновления нужно проверить автоматический возврат HTTP и VPN после контролируемого завершения только нашего процесса. Действующие туннели и правила не удаляются; предусмотрен отложенный запасной запуск. Рабочие кандидаты обновляются только после повторной проверки VPN. Отключение питания, USB и физического WAN не имитируется.
