# Сортировка, страницы и фильтры

Проверены управление списками трафика и журналом, сочетания поиска, устройства, направления сортировки и VPN/direct-фильтра, а также загрузка при медленных и ошибочных ответах API.

На живом API прошли 59 проверок: четыре поля сортировки в обе стороны и трёх scopes; суммы и количество записей; фильтры устройств; последовательные страницы без повторов; выход за последнюю страницу; поиск с `%`, `_` и отсутствующим значением; уровни журнала. Существующие SQL-матрицы сортировки, фильтров и пагинации также прошли.

В браузере воспроизведены и исправлены ошибки:

- Задержавшийся ответ старого фильтра журнала заменял записи нового фильтра. Запросы отменяются; данные и курсор сбрасываются при смене фильтра, в том числе если новый запрос завершился ошибкой.
- Смена фильтра трафика до завершения первого запроса оставляла страницу и кнопки в состоянии загрузки. Завершить загрузку теперь может актуальный запрос; фоновое обновление пропускается, пока предыдущий запрос не окончен.
- Отказ истории устройства блокировал успешный ответ списка сайтов: под выбранным устройством оставались глобальные данные. Успешные части ответа публикуются независимо, ошибочная история очищается. При изменении запроса показывается загрузка, без старых строк под новым фильтром.
- Подгрузка журнала по смещению могла повторять или пропускать записи при добавлении событий между страницами. Новый интерфейс использует курсор по `(occurred_at, id)`, связанный с выбранным уровнем. Старый offset API сохраняется. Новые события появляются после обновления; интерфейс сообщает об изменении журнала, если текущая выдача закончилась раньше актуального общего счётчика.

Регрессионные Go-тесты воспроизвели изменение журнала между страницами, неверные курсоры и переход с курсором другого фильтра. Проверены ответы API и совместимость offset-пагинации. Полный `go test -race ./...`, `go vet ./...`, 32 frontend-теста и production-сборка прошли; выполнено независимое ревью.

Браузерный стенд подтвердил отмену старых ответов, корректный отказ нового фильтра, завершение загрузки после отмены первого запроса, 11 строк выбранного устройства вместо 65 глобальных при отказе истории, отсутствие повторов при вставке нового события, сброс страницы при сортировке, оба направления сортировки и поиск. Направление сортировки доступно через `aria-sort`.
