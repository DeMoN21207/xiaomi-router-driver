# Разделы маршрутизации

«Сейчас работает» открывается первым и показывает одну текущую схему: совокупность используемых серверов и списков. Для каждого списка видны выбранный сервер, автоматический или ручной режим, переключение и возврат к автовыбору. Временный failover отображается по фактическому решению. Если автопереключение общего списка выключено, кнопка ведёт к настройке серверов, не меняя его скрыто и не отправляя несовместимое изменение серверу.

«Настройка маршрутов» содержит две вкладки: домены по серверам и автопереключение с резервами/расписанием. Редактируется один маршрут или один набор серверов за раз. Формы показывают действия рядом с полями. Сохранение политики сохраняет её `ruleId`; изменение порядка выполняется до сохранения и не переключает текущий сервер.

«Подписки и серверы» содержит источник подписки, доступные серверы и проверки задержки. Выбор уже настроенного сервера открывает существующий маршрут без создания дубля.

Обзор берёт владение записями из `effectiveRules` ответа GET `/api/rules`, а поля для сохранения из исходных `rules`. Поэтому старые собственные копии общего списка не изображаются отдельными работающими туннелями. API переключения поддерживает также временную политику `shared-domain-list`, не записывая её в конфигурацию.
