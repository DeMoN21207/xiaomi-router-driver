# Общий список и свои домены

На странице подключений общий список редактируется в одном месте. У каждого сервера есть собственный список и галочка «Добавить общий список»:

- С галочкой используются общий список и свои домены вместе.
- Без галочки используются только свои домены.
- Удаление последнего своего домена сохраняет сервер и положение галочки.

Общие записи получают один маршрут через основной доступный сервер. Другие участники общего списка служат резервом и одновременно сохраняют отдельную маршрутизацию своих доменов. Автовыбор и расписание для DeepSeek или другого отдельного списка сохраняются.

Старые копии общих записей в собственных списках не создают дублирующие маршруты. При совпадении между участниками общего списка учитывается порядок `sharedDomains.ruleIds`. Родительский домен покрывает свои поддомены по границе точки. Пересекающиеся IPv4-диапазоны разделяются в оперативных правилах с сохранением непересекающегося остатка. Сохранённые списки не переписываются. Конфликты с независимыми списками проверяет сервер API.

Карточка подписки показывает фактически выбранные серверы общего и отдельных списков, включая автоматическое переключение. Учётные данные, добавление серверов, диагностика и настройки автовыбора доступны в раскрываемых разделах.

Проверки: Go `test -race ./...`, `go vet ./...`, 20 frontend-тестов, production-сборка, независимое ревью; поиск, сохранение общего списка, редактирование своих доменов и переключение галочки проверены в браузере с вымышленными данными. Мобильная ширина 390 px проверена без горизонтальной прокрутки.
